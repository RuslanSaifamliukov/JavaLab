# JavaLab

Лабораторная работа №1 «Знакомство с языком программирования Java».
Лабораторная работа №2 «Знакомство со средой разработки Eclipse».

## Структура проекта

- `src/lr1` — задачи для самостоятельной работы (Example1–Example5 / Task1-Task10)
- `src/lr2` — задачи для самостоятельной работы (Task1–Task5)
- `src/lr3` — задачи для самостоятельной работы (Example1 / Task1-Task10)
- `src/timus` — решения задач с сайта acm.timus.ru:
  - `timus_1000` — задача 1000 «A+B Problem»
  - `timus_1068` — задача 1068 «Сумма»
  - `timus_1083` — задача 1083 «Факториалы!!!»
  - `timus_1264` — задача 1264 «Трудовые будни»
  - `timus_1293` — задача 1293 «Эния»
  - `timus_2001` — задача 1000 «Математики и ягоды»

## Тестовые данные

- 1000: вход `1 5`, выход `6`
- 1068: вход `-3`, выход `-5`
- 1083: вход `9 !!`, выход `945`
- 1293: вход `5 2 3`, выход `60`
- 1264: вход `3 1`, выход `6`
- 2001: вход `1 2, 2 1, 0 3`, выход `1 1`
